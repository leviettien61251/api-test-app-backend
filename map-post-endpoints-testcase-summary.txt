1. postAreaTest
============================================================

Endpoint:
POST /api/v1/map/area

Body hợp lệ:
{
  "areaId": "AREA_001",
  "mapId": 1
}

Field rules:
- areaId:
  - Required
  - Non-null
  - Non-blank sau trim
  - Type: String
- mapId:
  - Required
  - Non-null
  - Type: integer JSON number
  - Value > 0
  - Phải tồn tại trong MapTest
- areaId không được trùng trong AreaTestRepository.

Success response data:
[
  {
    "areaId": "AREA_001",
    "mapId": 1
  }
]

Response codes:
- 1000 SUCCESS:
  Insert thành công.
- 2006 MISSING_BODY:
  Body null/missing.
- 2001 MISSING_PARAM:
  Thiếu areaId.
  Thiếu mapId.
  areaId null.
  mapId null.
  areaId rỗng hoặc chỉ có whitespace.
- 2002 INVALID_TYPE:
  areaId không phải String.
  mapId không phải integer JSON number.
- 2003 INVALID_VALUE:
  mapId <= 0.
  areaId đã tồn tại.
- 4001 FLOOR_NOT_FOUND:
  Không tìm thấy mapId trong MapTest.
- 5000 INTERNAL_SERVER_ERROR:
  Exception ngoài dự kiến.
- 2005 INVALID_BODY:
  JSON invalid/parse lỗi.

Gợi ý testcase:
- Body null.
- Body {}.
- Thiếu areaId.
- Thiếu mapId.
- areaId null.
- mapId null.
- areaId "".
- areaId "   ".
- areaId number.
- mapId string.
- mapId decimal.
- mapId <= 0.
- mapId không tồn tại.
- areaId trùng.
- Body valid.

  - Non-null
  - Non-blank

- SQL timestamp: 2026-06-03 05:30:00
